# 酒馆音乐小组件

SillyTavern 的角色音乐 / 全局音乐播放器。

## v0.1.2

- 全局歌单
- 分角色歌单
- 角色切换时自动切换
- 播放、暂停、上一首、下一首、进度、音量
- 小型悬浮播放器
- PC + 移动端
- 音乐数据与主题数据分离
- 自定义 CSS 美化
- 主题 JSON 导入 / 导出
- 音乐数据 JSON 导入 / 导出
- 自定义悬浮按钮图片、播放器背景、强调色

## 安装

在 SillyTavern → 扩展 → 安装扩展程序中输入：

https://github.com/Paino47/-

安装后刷新酒馆。

## 使用

打开扩展设置中的「酒馆音乐小组件」。

### 分角色

在「音乐」页选择角色，然后填写：

- 歌曲名字
- 音频直链 URL
- 封面 URL（可选）

每个角色都有自己的歌单。

### 全局

选择「全局歌单」，添加的歌曲不会绑定角色。

### 自定义美化

进入「美化」：

1. 新建主题
2. 修改名称、作者、版本
3. 设置悬浮按钮图片
4. 设置播放器背景图片
5. 设置强调色
6. 直接编辑 CSS
7. 保存并应用
8. 导出 JSON

别人制作的主题也可以直接导入。

**主题导入不会覆盖音乐数据。**

## 主题 JSON

主题文件使用独立 JSON 格式：

```json
{
  "schemaVersion": 1,
  "id": "my-theme",
  "name": "我的主题",
  "author": "元素四十七",
  "version": "1.0.0",
  "description": "",
  "variables": {
    "accent": "#9acbff",
    "launcherImage": "",
    "backgroundImage": ""
  },
  "css": ""
}
```

## 音频 URL

必须填写浏览器可以直接访问的音频文件地址，例如 mp3、m4a、ogg、wav。

网盘分享页、网页播放页通常不是音频直链，不能直接作为歌曲 URL。
