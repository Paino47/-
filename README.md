# 角色音乐播放器

SillyTavern 第三方扩展：全局音乐 + 角色绑定音乐 + 独立可替换皮肤。

作者：元素四十七

## v0.1.0

- 标准第三方扩展结构
- 保留原仓库已有音乐组件数据
- 全局歌单 / 分角色歌单
- 角色本地绑定，不修改角色卡
- 全局显示 / 仅绑定角色显示
- 全局皮肤 + 角色专属皮肤 URL
- 内置「黎奖·逍遥留白」独立 CSS 皮肤
- PC + 移动端
- 音量、循环、数据导入导出

## 安装

在 SillyTavern → 扩展 → 安装扩展程序中输入：

https://github.com/Paino47/-

安装后刷新酒馆。

## 使用

打开顶部「扩展」里的「角色音乐播放器」。

### 绑定自己的角色

1. 打开你自己的角色卡。
2. 打开「扩展」。
3. 在「当前角色」区域勾选「绑定当前角色」。
4. 在歌单区域选择当前角色并添加歌曲。
5. 需要角色专属美化时，在「当前角色皮肤 CSS URL」填写 CSS 地址。

绑定信息只保存在本地扩展设置，不会写进角色卡。

### 皮肤

插件自带：

skins/lizhang.css

它就是第一套「黎奖·逍遥留白」皮肤。

以后可以直接新增独立 CSS 皮肤，不需要改播放器核心。

优先级：

角色皮肤 > 全局皮肤 > 内置黎奖皮肤
